# Three artefacts manufacture a "weight-loss toxin rebound" alarm

Analysis code, result tables and verification record for the manuscript submitted to
***Obesity*** as a Brief Cutting Edge Report (2026).

> **Yuan Z.** Doctoral Programme in Planetary Health Studies, University of Lisbon, Lisbon 1649-013, Portugal.
> Correspondence: yuan-zizheng@edu.ulisboa.pt

The paper asks a narrow question: when a study reports that weight loss mobilises persistent
organic pollutants and thereby accelerates biological ageing or blunts androgen recovery, how much
of that signal can be generated by the data-generating process itself? Three candidate mechanisms
are tested — confounding, unmeasured prescribing, and scores that contain body mass — and what
remains after they are removed is examined.

---

## 1. What is here, and what is not

Everything in this repository was produced by the scripts in `code/` from public data. Only two
corrections were ever applied by hand, and both are documented with before/after estimates: a CRP
unit conversion (`verification/crp_unit_adjudication.csv`) and a re-specified interaction term
that had dropped the intercept (`verification/coef_stability_diag.csv`, with the size of the
correction in `BriefComm_Obesity/supplement/TableS2_statistical_audit.csv`).

| Included | Not included (regenerable, and large) |
|---|---|
| All analysis scripts (`code/`) | Raw NHANES XPT files (2.9 GB, 200 files) — see `code/01_download_nhanes.sh` |
| All result tables as CSV (`results/`) | Intermediate `.rds` objects (`data/derived/`, 40 MB) — see `code/05_build.R` |
| All verification outputs (`verification/`) | Fitted causal-forest object (`cf_results.rds`, 95 MB) — see `code/10_causal_forest.R` |
| All figures, PNG + PDF (`figures/`) | GEO pseudobulk matrix (50 MB) — see `code/14_geo.R` |
| Full report and appendix (`report/`) | Per-cell score matrices from GEO (`*.csv.gz`, 57 MB) |
| Numbered evidence pack (`evidence_pack/`) | Single-cell objects rebuilt from GEO (`verification/_tmp/`, 63 MB) |
| Submission package (`BriefComm_Obesity/`) | CDC codebook HTML pages (4.7 MB) — available from cdc.gov |

**Data sources.** NHANES 2003–2023, eight cycles: 2003–2004 (C), 2005–2006 (D), 2009–2010 (F),
2011–2012 (G), 2013–2014 (H), 2015–2016 (I), 2017–March 2020 (J), 2021–2023 (L). The 2007–2008
cycle is **not** part of this analysis, because the pollutant panel was not fielded in that cycle.
Linked mortality files follow participants through 31 December 2019.
Single-cell data: GEO **GSE295708**; external bulk validation: GEO **GSE199063**.
Protein structures: PDB **1D2S** (human SHBG, 1.95 Å) and **1E7I** (human serum albumin); ligand
geometries from PubChem 3D conformers.

### How to read `evidence_pack/`

`evidence_pack/INDEX.csv` has one row per claim: `id` (`E<act>-<n>`), the section of the
manuscript it supports, the claim itself, the numbered file that supports it, the original file it
was copied from, the script that generated it, and the key number. The numbering follows the order
of the argument, not the order of the filesystem, and one original file may carry two numbers when
it supports two steps of the argument. The numbered files are byte-identical copies of the
originals in `results/`, `verification/`, `figures/` and `report/`; they are kept so that a claim
can be traced without knowing the project layout. `00_story/storyline.md` is the narrative the
numbering was built for.

### How to read `verification/verification_ledger.csv`

256 rows, 33 source files. Each row is one number in the manuscript, the file it came from, and its
verdict. `VERIFICATION_SUMMARY.md` renders the same ledger as tables, grouped into five layers:

| Layer | What it checks |
|---|---|
| L1 | File provenance: SHA-256 of all 208 downloaded files, 200/200 byte-identical to CDC |
| L2 | Structural integrity: key uniqueness, join fan-out, 9 published anchor values |
| L3 | Units and sentinels: cross-cycle unit jumps (125 variable–cycle pairs), missing-value sentinels (4,135 values set to NA) |
| L4 | Re-derivation: independent Python implementation against R, bisection cross-check of the free-testosterone equation, cluster label reproduction |
| L5 | Robustness: leave-one-PSU-out, permutation inference, survey weights, LOD substitution, E-values |

## 3. Reproducing the analysis

Environment: R 4.4.2 (Windows 11 x64); `data.table` 1.18.2.1, `grf` 2.6.1, `survival` 3.7.0,
`ggplot2` 4.0.3, `patchwork` 1.3.2, `haven`, `digest` 0.6.39; Python 3 with `pandas`, `numpy`,
`scipy`, `statsmodels`. Full snapshot in `verification/environment_snapshot.txt`.

Scripts read and write relative to a single root, taken from the environment variable `AGE22_ROOT`
and defaulting to the working directory. Run everything from the repository root:

```bash
export AGE22_ROOT="$(pwd)"            # Windows: set AGE22_ROOT=%CD%

bash code/01_download_nhanes.sh       # about 2.9 GB from cdc.gov
bash code/02_download_mort.sh         # linked mortality files
Rscript code/05_build.R               # merge cycles by SEQN  -> data/derived/core.rds
Rscript code/06_build_pop.R           # adult population, PFAS molar sums
Rscript code/09_prep_analysis.R       # analysis frame, propensity-score trimming
Rscript code/10_causal_forest.R       # causal forest, seeds fixed at 2026
Rscript code/11_param.R               # parametric and AIPW counterparts
Rscript code/22_androgen_axis.R       # androgen panel
Rscript code/36_inflam_clean.R        # the 30 interaction cells re-estimated
# ... remaining scripts in numeric order
Rscript code/verify/V15_ledger.R      # rebuild the 256-row ledger
python  code/verify/build_evidence_pack.py
```

`logs/` holds the console output of the run that produced the deposited tables, so a discrepancy
between a fresh run and a deposited CSV can be localised to a single script.

Figures: `code/16_figures.R`, `code/18_fig_geo.R`, `code/26_fig_androgen.R`,
`code/35_fig_breakthroughs.R` and `struct_pfas/fig14.py`. The two submission figures and the
.docx files are produced by `BriefComm_Obesity/code/make_figures_bc.py` and
`BriefComm_Obesity/code/build_docx.py`.

| Albumin (negative control) | +0.20% (P=0.29) | `results/androgen_bioavailability.csv` |

One caution governs the reading of the androgen result: **%free testosterone is a deterministic
function of SHBG and albumin** in the Vermeulen equation. The −2.3% follows arithmetically from
SHBG (+4.78%) rising faster than total testosterone (+4.02%), with albumin flat (+0.20%). It is a
statement about how the androgen result should be read, not an independent finding, and free
testosterone itself did not change measurably (+1.62%, P=0.16).

## 5. Notes on the deposited code

- **Paths.** In the working copy each script opened with a hard-coded absolute root; for deposit
  the root is read from `AGE22_ROOT` instead, defaulting to the working directory. No analytical
  statement, seed, formula or filter was changed, and the deposited tables are those the deposited
  scripts produce.
- **Files not deposited.** The exploratory directories `code/scratch/` and `code/verify/_scratch/`
  (28 fragments that never produced a deposited number) and `verification/before_crpfix/` (the
  pre-correction inflammatory estimates) are excluded so that the record stays unambiguous. The
  corrected values and the size of the correction are in `verification/crp_unit_adjudication.csv`.
- **Language.** Code comments and the two long report files are in Chinese; all tables, figure
  labels, the manuscript and the supplement are in English.
- **Known limits of the verification.** `lod_audit.csv` reports the percentage of values below the
  limit of detection per congener and cycle; congeners with more than 30% below the limit were
  re-estimated by substitution (`lod_substitution_sensitivity.csv`). The literature audit in
  `BriefComm_Obesity/02_field_audit.csv` screened the abstracts of all 12 included studies and the
  full texts of the 4 adult-male studies; this is stated in Supplementary S9 and should not be
  read as a full-text review of all 12.
