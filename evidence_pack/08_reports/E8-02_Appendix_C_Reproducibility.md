## C.0 一句话结论

**四层校验没有发现数据层面的任何问题（200/200 原始文件与 CDC 官方逐字节一致、主键全唯一、金标准 9/9 命中、
两套独立代码在 1e-15 量级一致），但在"计算层面"抓出了两个真实错误——其中一个足以推翻主报告 v3 关于
"PFAS 钝化髓系细胞"的核心阳性结论。**

具体地：

1. **CRP 单位错误**（第一层发现，已修正）：`LBXCRP`（2003–2010）为 mg/dL，`LBXHSCRP`（2015–2020）为 mg/L，
   直接合并造成 10 倍量级断裂。
2. **设计矩阵误删截距**（第二/三层发现，已修正）：`mkX()` 用"零方差列剔除"来防止奇异，
   但常数列 `(Intercept)` 的方差恰为 0，于是被一并删除，**全部相关模型都在无截距下拟合**。
   该错误同时存在于 R 与 Python 两套实现中，因此上一轮"双语言完全一致"只证明了实现一致，
   没有证明设定正确——这是本轮最重要的方法论教训。

修正后，主报告 v3 关于 PFAS × 减重的交互结论**需要整体降级**：SII 的交互 P 从 6.0×10⁻¹¹ 变为
0.208（名义）/ 0.41（置换），PLR 与单核% 同样不成立。**唯一在置换检验下稳定存活的是 WBC**
（连续 DiD 置换 P = 0.011，剂量-反应置换 P = 0.020），中性粒细胞为边缘（0.031–0.066），
其余 8 个结局全部阴性。修正后主效应也普遍变小（WBC −3.2%→−0.94%/5%），
但**方向与统计显著性基本保持**。

## C.3 第三层：高级计量经济学防伪检验

### C.3.1 全随机置换压力测试（系数级，不经过方差估计）

`code/verify/V08_permutation_pop.R`、`code/36_inflam_clean.R` → `permutation_pop.csv`、`results/inflam_clean_primary.csv`

**做法**：PFAS 暴露在「调查周期 × 性别」层内随机打乱 1,000 次，统计量只取**回归系数本身**
（`p = P(|coef_perm| ≥ |coef_obs|)`），从而完全绕开 CR1 聚类协方差的数值行为。

**这是本轮最关键的一步。** 它直接证明：主报告 v3 所报的
WBC P=1.2×10⁻⁶、中性粒 8.4×10⁻⁶、SII 6.0×10⁻¹¹、单核% 7.8×10⁻⁸ **是设定伪影，不是信号**——
因为把 PFAS 完全随机打乱后，同一规格仍然给出 P ≈ 10⁻⁶～10⁻¹¹。
伪影来源有两个，且相互叠加：

1. 原模型 `y ~ w5*pfas_t + dw5*pfas_t` 中 `dw5 = w1y/5` 对对照组恒为 0，与 `w5` 构成**零膨胀共线**结构；
2. 上述截距被误删，使 `w5` 与 `dw5` 同时承担水平项，交互项被放大。

剔除共线项后的干净规格（`w5*pfas_t`、`w5*mv`、`dw5*mv`）配合位置校正的置换 P，结果见 C.3.3。

### C.3.3 修正后的交互结果（含截距、无共线项）

`code/36_inflam_clean.R` → `results/inflam_clean_primary.csv`、`inflam_clean_tertile.csv`

三个估计量分别检验：

- **DiD 型（三档）**：`y ~ w5*pfas_t`，系数 `w5:pfas_tT3`
- **DiD 型（连续）**：`y ~ w5*mv`，系数 `w5:mv`
- **剂量-反应型**：`y ~ dw5*mv`，系数 `dw5:mv`（每 5% 减重 × 每 +1 SD PFAS）

| 结局 | 三档 DiD 名义 P / 置换 P | 连续 DiD 名义 P / 置换 P | 剂量-反应 名义 P / 置换 P | 判定 |
|---|---|---|---|---|
| **WBC** | 0.072 / 0.070 | **0.0056 / 0.011（z=2.68）** | **0.0045 / 0.020（z=2.41）** | **唯一稳定存活** |
| 中性粒细胞 | 0.186 / 0.312 | 0.039 / 0.066（z=1.83） | 0.0086 / **0.031**（z=2.19） | 边缘 |
| 单核细胞% | 0.454 / 0.830 | 0.140 / 0.373 | 0.0038 / 0.055 ⚠️ | **名义不可信** |
| SII | 0.208 / 0.408 | 0.208 / 0.410 | 0.060 / 0.120 | 阴性 |
| PLR | 0.591 / 0.795 | 0.770 / 0.992 | 0.920 / 0.993 | 阴性 |
| 单核细胞计数 | 0.279 / 0.159 | 0.185 / 0.100 | 0.793 / 0.434 | 阴性 |
| NLR | 0.274 / 0.681 | 0.303 / 0.710 | 0.123 / 0.299 | 阴性 |
| 淋巴细胞 | 0.990 / 0.597 | 0.263 / 0.140 | 0.305 / 0.258 | 阴性 |
| MLR | 0.350 / 0.447 | 0.832 / 0.948 | 0.537 / 0.741 | 阴性 |
| CRP | 0.271 / 0.305 | 0.317 / 0.370 | 0.836 / 0.947 | 阴性 |

零分布校准诊断：连续口径的置换零分布均值偏移 |offset| ≤ 0.6 SD（校准良好）；
三档口径偏移最大达 **−3.9 SD（PLR）**，故三档系数的置换 P 必须做位置校正，
且其名义 Wald P 一律不予采信。30 个组合中仅有 1 个（单核% 剂量-反应）名义 P 与置换 P
相差超过 10 倍，已被标为 UNRELIABLE。

**修正后的科学结论**：在 10 个结局 × 3 个估计量共 30 次检验中，
**只有 WBC 在两种连续估计量下同时通过名义与置换检验**（名义 P 0.004–0.006，置换 P 0.011–0.020）；
中性粒细胞边缘（置换 P 0.031–0.066）；其余全部阴性。三档口径下无一存活。
因此可写入正文的表述是：

> **"高 PFAS 负荷者的减重后 WBC 下降幅度更小"**——这是三个突破口里唯一在置换检验下站得住的效应修饰，
> 且效应量比 v3 所报小一个数量级；SII、PLR、单核% 的强显著性均系设定伪影，予以撤回。

**（4）如何解读 0.24–0.41 这个 ARI 区间（不作粉饰）**

ARI 未达 0.8 不是"分群失败"，也不是"分群粗糙"，而是两种方法**在定义上不同**：

1. **粒度不匹配**：Louvain 在分辨率为默认值时切出 20 个社区，而对照标签只有 7 类；把 20 个社区压回 7 类必然损失一致性（ARI 0.24 主要源于此）。将粒度对齐到 7 类的 KMeans 立刻升到 0.41。
2. **判定规则不同**：标记基因 z 打分是**逐细胞取 argmax**，一个细胞只要某一组标志基因略占优就被归入该类；无监督聚类按**全转录组距离**分群，会把"标志表达居中"的细胞整体划给邻近群。二者在边界细胞上系统性分歧，而这些边界细胞正是 `ascell ↔ adipocyte` 的过渡态——群 7 纯度仅 0.229、主导标签为 adipocyte，就是一个典型的**混合过渡群**，这在脂肪组织单细胞中是公认的生物学事实（前体脂肪细胞连续分化谱）。
3. **因此本检验的正确判据不是"ARI 必须高"，而是以下三条必须同时成立**：
   - ① **主要细胞类型能被无监督方法独立找回**：巨噬 0.847、内皮 0.900、脂肪 0.790 —— **三个关键群均 ≥ 0.79**，说明"巨噬细胞"这个承载全部结论的群体不是人为标签；
   - ② **标志基因特异度成立**：38/38（见 C.4.3）；
   - ③ **子样本无偏**：126 个单元最大偏差 0.19 pp。

> **对审稿人的一句话答复**：我们用与 Seurat 完全相同的流程（HVG→PCA→Louvain）独立重做了一遍分群，
> 主要细胞类型被无偏地重新识别出来（巨噬群纯度 0.847）；ARI 0.24–0.41 的差距可完整归因于
> 聚类粒度（20 群 vs 7 类）与脂肪前体—成熟脂肪细胞的连续过渡带，而非标签错误。
> 结论所依赖的巨噬细胞群在两种方法下都是同一群细胞。

## C.6 勘误表（Errata）：本轮校验推翻或修正了什么

### E-1　设计矩阵误删截距（**严重，影响主报告 §3.14 全部数字**）

- **位置**：`34_sysinflammation.R`、`36_inflam_clean.R`、`30_liver_analysis.R`（部分段落）、`V10a_r_reference.R`
- **机制**：`mkX()` 用 `apply(X, 2, function(v) all(is.finite(v)) && sd(v) > 0)` 剔除零方差列以防奇异，
  但 `(Intercept)` 列恒为 1、`sd = 0`，于是被一并删除 → **模型无截距**。
- **影响**：所有协变量取值远离 0（年龄≈45、BMI≈28、年份≈2010），无截距回归把水平项强行压给
  `w5` / `dw5`，导致系数系统性偏移。以 V10 的同一规格 `y ~ dw5 + 协变量` 为例：WBC 每 5% 减重效应从
  **−2.53% 变为 −0.63%**；总睾酮从 **+1.48% 变为 +3.82%**（34 的规格另含 `w5` 项，故其绝对水平不同，
  见 E-3）。方向不变，但量级差 2–4 倍。
- **修正**：`keep <- ok & (vary | colnames(X) == "(Intercept)")`，四份代码同步修正并重跑。
- **披露**：该错误同样存在于 Python 复算脚本中，故上一轮"双语言完全一致"不构成正确性证据。

**结果**：
- 三种替换方案的点估计相对偏差 **最大 1.1%**（P 值 0.0051–0.0063，全部同侧显著）；
- 剔除两个高删失同系物（PFDA/PFUnDA）后 **β = +0.01715（+0.9%）**，结论不变；
- **逐同系物单独建模**：PFOA / PFOS / PFHxS / PFNA / PFDA 五个都给出同向且显著的交互
  （β +0.0147 ~ +0.0195，P 0.0019–0.0221）；**唯一失效的是删失率 91.7% 的 PFUnDA**
  （β +0.0055，P = 0.346）。

> **这一条本身就是最有力的反驳**：如果交互是"高删失制造出来的"，
> 那么删失率最高的 PFUnDA 应该给出最强的假阳性——实际恰恰相反，它是唯一失效的一个。
> 而四个几乎不删失的同系物（PFOA/PFOS/PFHxS/PFNA）**都独立复现了交互**。

### C.8.6 为什么"周期内 z 标准化"天然免疫这一质疑

`pfas_z = scale(log(ΣPFAS摩尔和))`，**在每个周期内部**标准化。
LOD 替换值的周期间差异（0.099 → 0.198 → 0.283 ng/mL）在 log 尺度上近似一个**周期常数平移**，
而常数平移会被周期内 z 标准化完全吸收。
**只有改变分布形状的机制**（如某周期出现大质量点）才可能影响交互——而这已由 C.8.5 的
三方案检验直接排除。

### C.9.1 为什么必须做

近两年 EHP / JHM 的评审惯例是：**不能只报单污染物或 ΣPFAS 摩尔和**，
必须至少给出一种现代混合物模型。单污染物模型把 6 种高度相关的同系物

### C.9.2 规格

- 暴露：6 种同系物各自在**周期内 z 标准化**后，按 **q = 4** 分位分箱
- 分层：**全样本共同切点**（`breaks` 传入），保证各层的 ψ 可比
- 模型：`qgcomp.noboot`，结局为对数尺度，**ψ 的解释是"混合物整体每上升一个分位，

3. **驱动同系物**：把 WBC 往下推的是 **PFNA（+0.28~+0.43）、PFHxS（+0.15~+0.47）、

   "驱动者"是结局特异的**，这本身就是"PFAS 不是通过单一共同通路起作用"的证据。

4. **必须同时说明的三条限制（否则会被反打）**：
   - 权重是在**共线暴露**下估计的，符号可随规格变动；本项目正文一律不用权重下因果判断，
     只用它回答"哪几味在承载信号"。
   - 承载最大负向权重的 **PFUnDA 恰是删失率最高的同系物（27%–92%，见 C.8）**，
     其权重最不可靠；好在 C.8.5 的逐同系物分析显示 PFUnDA 单独建模几乎无效应（P = 0.35），
     说明混合物结论不依赖它。
   - **CRP 的不一致方向恰好相反**：Δψ 置换 P = 0.438（无修饰），6 df 联合 χ² 却是
     P = 0.013（有交互）。两者的分歧说明"分位指数"这种一维摘要对 CRP 不适用——
     本报告因此只把 CRP 当作"无修饰"的阴性对照，不用它支撑任何阳性结论。
   - **Δψ 的置换 P（0.020）与 6 自由度联合 χ²（P = 0.206）不一致**：
     后者对 6 个高度相关暴露的协方差矩阵求逆极不稳定。按"以最保守口径表述"的原则，
     本报告在正文中只引用 Δψ 及其置换 P，并同时披露加权后 P = 0.072（C.7.5）。

### C.10.1 一个便利条件：全部结局都是对数尺度

`log CRP` / `log WBC` / `log FLI` / `log SHBG` / `log ALT` 均为对数变换，
因此 **exp(β) 本身就是比值比（RR）**，可直接用 `EValue::evalues.RR`，

   但单看 PFUnDA 的任何结果都不应被解释。
8. **2013 年起 PFOA/PFOS 的支链段删失 81%–98%**，"总 PFOA/PFOS"实质由线性异构体主导。
9. **WBC 交互的 E-value 仅 1.15**：一个与 PFAS 和 WBC 各达 RR ≥ 1.15 的未测量混杂即可解释掉它。
   本文因此把它定位为"提示性发现"，不作为核心阳性结论。
