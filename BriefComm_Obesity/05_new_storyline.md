# 新故事线：命题、证据链、与旧稿的差别

> 2026-11-21。旧稿备份在 `manuscript/_archive_v1/`。本文件说明改稿后每一句话由哪个文件支撑。

## 一句话命题

**"减重释放毒素"叙事的两条核心预测——减重者血清污染物更高、生物学年龄更老——在同一份 NHANES 数据里都不成立；而看起来成立的表象，可以由四条互不相同的分析路径生成，且它们方向不一致。**

## 为什么这条线能立住

旧稿的骨架是"三个伪影都偏向有害"。这句话被 SII 的反例推翻（同一个 bug 把 −8.0% 放大成 −1.0%），所以不能再用。

新稿改用一个**可证伪的预测检验**做骨架：不做"文献里的警报是假的"这种无法在本数据内验证的主张，只做"这两条预测在我们能检验的数据里成不成立"。结论是硬否定，且有等价性检验兜底。

## 与旧稿的四个实质差别

1. **主语换了。** 旧稿讲"三种伪影制造了假警报"，新稿讲"两个可检验的预测不成立"。前者需要证明文献里的警报都是假的（做不到），后者只需要证明这两条预测在本文数据里不成立（做到了）。
2. **论证方向换了。** 旧稿靠"三个伪影都朝坏的方向偏"来立论，新稿把这个变成反证：四条路径方向不一致，所以方向不能当伪影的诊断。SII 从打脸变成证据。
3. **结论强度换了。** 旧稿说"调整后是获益（−0.33）；新稿说"调整后与 0 无法区分，且能排除大于 1 年的危害"。后者更弱，但它是真的，且有 TOST 撑。
4. **临床落点换了。** 旧稿说"真正该警惕的是游离睾酮比例下降"；新稿说"绝对游离睾酮没变，变的只是比例的算术，读 TT 时别把它当作恢复"。从"新危害"降为"读法"。

## 仍然存在的风险

- **横断面**：PFAS 与体重的差异是"人际差异"，不是"同一个人减重前后"。这一点写进局限，并用"两条机制都预测升高、观察却更低"来加强，但没有解决。
- **只测一次 PFAS**：半衰期 3–7 年，一年窗口的释放效应可能小到测不出。局限里写明"重复测量队列仍可能检出"。
- **森林不可复现**：如果审稿人追问，只能答"运行级非确定性，已如实报告，故不作为证据"。这是弱点，但诚实报告比藏起来好。
- **审计只有 12 篇，8 篇仅摘要**：如果要当主菜，需补全文核对。目前它只是 Discussion 里的一段。
- **期刊错配**：这篇现在更像暴露科学的方法学短文，*Obesity* 是临床刊。投 *Obesity* 的把握低于投 JESEE 或 EHP。
